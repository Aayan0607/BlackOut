# Physical device acceptance checklist

These checks require actual devices. Automated browser tests are complementary evidence.

## Setup

- [ ] Serve the production `dist/` build from an HTTPS origin.
- [ ] Load on two camera-equipped devices. Record OS/browser versions.
- [ ] Assign different device labels and wait for offline readiness on both.
- [ ] Create the expedition once and transfer it to the other device.

## Offline operation

- [ ] Disable cellular networking, Wi-Fi, and Bluetooth explicitly.
- [ ] Close/reopen or reload BlackOut on both devices; existing records remain.
- [ ] Add independent field records on both devices.
- [ ] Edit the same existing assignee differently.

## Optical transfer

- [ ] Allow camera access; scan the other screen at normal brightness.
- [ ] Rotate all frames and confirm the progress count increases.
- [ ] Stop midway, reopen the receiver, and continue the unchanged transfer.
- [ ] Review and import; observe both additions and the conflict.
- [ ] Send the combined snapshot back; compare records on both devices.
- [ ] Rescan the same snapshot; no duplicate records appear.
- [ ] Resolve the conflict and exchange that resolution.

## Recovery and presentation

- [ ] Export a backup and import it into a separate browser profile.
- [ ] Verify the app's useful error when camera permission is denied.
- [ ] Record a 3-minute demo and keep the video available locally.
- [ ] Mark measured results honestly; do not describe a simulator as a physical transfer.

Optional after the core passes: relay A's observation through B to C while A is absent.

## Phase 2 field workflow

- [ ] Create an assigned checkpoint at Camp 2 and a hazard at the same location on separate devices.
- [ ] Exchange both ways, then inspect their shared location group in Checkpoint board.
- [ ] Open the checkpoint from the board, mark it done, and exchange the decision.
- [ ] Confirm completed checkpoints exclude unresolved conflicts.
- [ ] Filter records by category and assignment, then clear the filters.
- [ ] Find both device labels in Activity and open a record from its event.
- [ ] Repeat board, filtering, and activity use after an offline reload.
